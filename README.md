# FoodWheel

An interactive React + Vite web application to help you decide what to eat! Spin the "Wheel of Eats", add your own choices, and let fate decide your next meal.

## Features

- **Interactive Spin Wheel**: Smooth animations and realistic physics.
- **Custom Choices**: Add up as many as 16 custom choices.
- **Auto-Emoji Detection**: Emojis are automatically assigned based on your food name.
- **Dark Mode Aesthetic**: A sleek, modern design that is easy on the eyes.

## Getting Started

### Prerequisites

Make sure you have Node.js installed.

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
